## Context

FlipJump currently uses a `Square` prefab (transparent SpriteRenderer + BoxCollider2D) as ground. The PinArrow project has a `Terrain - GroundShape` prefab using Unity's SpriteShape system, which renders textured terrain with spline-based shapes. The `com.unity.2d.spriteshape` package (v9.1.0) is already installed in FlipJump.

The level system uses JSON files (V2 format) with `LevelElement` objects containing prefab name, position, scale, rotation, and component data. The level editor auto-discovers prefabs from `Assets/Prefabs/`.

## Goals / Non-Goals

**Goals:**
- Create a `GroundShape` prefab with SpriteShapeController for visually rich terrain
- Copy core fill + surface edge textures from PinArrow and create a SpriteShape profile asset
- Serialize spline point data (positions, tangents) into level JSON so each level can have unique terrain shapes
- Integrate GroundShape into both the level editor (save/load) and runtime loader
- Keep GroundLiftZone working on GroundShape (it already uses BoxCollider2D bounds for width; GroundShape uses PolygonCollider2D so this needs adaptation)

**Non-Goals:**
- Multiple terrain themes (start with one theme, more can be added later)
- Open-ended spline with EdgeCollider2D (PinArrow's `OpenEndedSpriteShapeCollider`) — use closed shapes with PolygonCollider2D for simplicity
- Removing the Square prefab (backward compatibility)
- In-editor custom spline editing tools (Unity's built-in SpriteShapeController handles this)

## Decisions

### Decision 1: Store spline data as a separate field on LevelElement

**Choice:** Add a `splinePoints` array field to `LevelElement` containing serialized spline point data (position, left/right tangent, tangent mode). Only populated for GroundShape elements; null for others.

**Rationale:** Spline data doesn't fit the existing `ComponentData` model (which uses name/float pairs). A dedicated array field keeps the JSON clean and makes it easy to reconstruct the spline at load time. Using `JsonUtility` means we need `[Serializable]` classes.

**Alternative considered:** Encoding spline data as ComponentData properties with indexed names (e.g., `"point0_x"`, `"point0_y"`). Rejected — too fragile, hard to parse, and poor readability.

### Decision 2: GroundShape prefab uses PolygonCollider2D (auto-generated by SpriteShapeController)

**Choice:** Enable `UpdateCollider` on SpriteShapeController to auto-generate a PolygonCollider2D matching the shape.

**Rationale:** SpriteShapeController has built-in collider generation. No custom scripts needed. PolygonCollider2D is more accurate than BoxCollider2D for irregular terrain shapes.

### Decision 3: Adapt GroundLiftZone to work with PolygonCollider2D

**Choice:** Change `GroundLiftZone.Awake()` to also check for `PolygonCollider2D` when getting bounds width, not just BoxCollider2D.

**Rationale:** GroundLiftZone currently reads `BoxCollider2D.bounds.size.x` for zone width. GroundShape uses PolygonCollider2D. Both collider types expose `.bounds`, so the fix is to fallback to any `Collider2D.bounds`.

### Decision 4: Copy one texture set from PinArrow to start

**Choice:** Copy `core_stone.png` (fill) and `surface_grass.png` (edge) from PinArrow and create a single "Grass Stone" SpriteShape profile.

**Rationale:** One theme is enough to prove the system works. More themes can be added by creating additional SpriteShape profile assets.

## Risks / Trade-offs

- **[Risk] Spline data could make JSON files significantly larger** → Each spline point is ~7 floats (pos x/y/z, ltx/lty, rtx/rty, mode). A typical terrain with 5-10 points adds ~280-560 bytes — negligible.
- **[Risk] SpriteShapeController spline API may differ between Unity versions** → We target the installed version (9.1.0). The spline API (`spline.GetPointCount()`, `GetPosition()`, `SetPosition()`, etc.) has been stable since 2019.
- **[Risk] GroundLiftZone zone detection may not align well with irregular terrain shapes** → The lift zone uses an AABB overlap check, which is a rough approximation. This is acceptable since it already works that way with scaled Square prefabs.
